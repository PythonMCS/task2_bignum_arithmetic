# Задача №2. Длинная арифметика

Необходимо реализовать длинную арифметику для целых чисел с операциями сложения, вычитания, умножения и целочисленного деления.

Для представления длинных чисел используется система счисления с основанием `M`.
Максимальное количество разрядов числа ограничивается значением `N`.

## Установка

```bash
poetry install
```

## Запуск

```bash
poetry run task2
```

## Пример работы программы

```text
Длинная арифметика

Введите основание системы счисления M (>= 2): 10
Введите максимальное количество разрядов N (>= 1): 50

Выберите операцию:
1 - сложение
2 - вычитание
3 - умножение
4 - целочисленное деление
0 - выход

> 1

Введите первое целое число: 12345678901234567890
Введите второе целое число: 98765432109876543210

Результат: 111111111011111111100
```

## Представление чисел

Длинное число - это список разрядов в системе счисления с основанием `M`.

Разряды хранятся от младшего к старшему.

Например, при `M = 10` число:

```text
12345
```

представляется так:

```python
[5, 4, 3, 2, 1]
```

Знак числа хранится отдельно:

```text
1  - положительное число
-1 - отрицательное число
```

Ноль представляется в виде:

```python
[0]
```

## Алгоритм решения

Для работы с длинными числами реализованы операции над их абсолютными значениями.

### Нормализация

Функция нормализации удаляет незначащие нули.

Например:

```python
[5, 4, 0, 0] -> [5, 4]
```

Но число `0` останется представленным как `[0]`.

### Сравнение

Сначала сравнивается количество разрядов чисел.

Если количество разрядов одинаково, сравнение начинается со старшего разряда.

### Сложение

Сложение выполняется поразрядно, начиная с младших разрядов.

Если сумма разрядов превысит основание системы счисления `M`, выполнится перенос в следующий разряд.

### Вычитание

Вычитание выполняется поразрядно.

Если текущего разряда недостаточно для вычитания, одна единица занимается из следующего разряда.

### Умножение

Умножение реализовано как умножение столбиком.

Каждый разряд первого числа умножается на каждый разряд второго числа, а результат записывается в соответствующую позицию с переносами.

### Целочисленное деление

Деление выполняется начиная со старших разрядов делимого.

Для каждого разряда частного с помощью поиска определяется максимальное значение от `0` до `M - 1`, при котором произведение делителя на разряд не превышает текущий остаток.

### Работа со знаками

Операции над числами со знаком приводятся к операциям над их абсолютными значениями.

При сложении чисел с разными знаками из большего модуля вычитается меньший.

Знак результата определяется знаком числа с большим абсолютным значением.

При умножении и делении знак результата определяется знаками символов операций.

## Ограничение разрядности

Максимальное количество разрядов задается параметром `N`.

Если количество разрядов введенного числа или результата операции превышает `N`, программа сообщит о переполнении.
